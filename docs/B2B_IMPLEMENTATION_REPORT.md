- Neon, Vercel и Vercel Blob не удалены и остаются резервным исходным контуром.

## Реализовано

- Канонические поля товара: slug, цена с НДС, единица цены, упаковка, единиц в упаковке, минимальный заказ, описания, JSON-характеристики, поиск, подсказка покупателю, popular/sort, Meta ID и категории feed.
- Карточка товара с ценой единицы и упаковки, минимумом и понятным состоянием «фасовка уточняется».
- Корзина считает упаковками, хранится в `localStorage`, сохраняет менеджера и timestamp, предупреждает после 24 часов.
- Перед WhatsApp запрашиваются телефон и необязательное имя; сервер повторно проверяет товары, цены, фасовку и минимум, затем создаёт `CartSubmission` и формирует сообщение с номером заявки.
- Менеджеры хранятся в таблице `Manager`; работают `/catalog?manager=slug` и `/m/slug`, default fallback и сохранение менеджера в корзине.
- Внутренняя аналитика с visitor/session/event ID, UTM, manager/product/category, тестовым режимом, защитой от ботов, повторов и админских событий.
- Meta Pixel и CAPI используют один `event_id`; телефон хэшируется сервером. Интеграция безопасно неактивна без env-реквизитов.
- Публичный Meta-feed: `/api/meta-feed.csv`. В него попадают только активные товары с полной ценой и фасовкой; ID совпадает с Pixel/CAPI content IDs.
- Админка: расширенная форма товара, управление менеджерами, WhatsApp-заявки, отчёты по товарам/категориям/менеджерам, конверсии и суммы.
- Импорт с dry-run проверкой и массовым обновлением; экспорт UTF-8 CSV и Excel-compatible XML `.xls`.
- Цены без НДС больше не вычисляются и не показываются покупателю автоматически.

## Защитный запуск

`AppSettings.cartEnabled=false`. Это сознательное состояние production: каталог доступен, но оформить корзину нельзя, пока не заполнены реальные фасовки.

Фактические пробелы восстановленных данных:

| Поле | Товаров без значения |
|---|---:|
| `priceWithVat` | 44 |
| `unitName` | 0 |
| `packageType` | 87 |
| `unitsPerPackage` | 450 |
| Полностью готовых к заказу товаров | 0 |

Никакие фасовки, цены или технические характеристики не были выдуманы.

## Нужны от владельца

1. Реальное количество единиц в упаковке для товаров; при необходимости — тип упаковки для 87 товаров и цена с НДС для 44 товаров. Удобнее заполнить через экспорт/импорт.
2. Имя и WhatsApp-номер второго менеджера. Сейчас восстановлен только один default-менеджер со slug `a`; после добавления в админке появится `/m/b`.
3. Для Meta: `META_PIXEL_ID`, `META_CAPI_ACCESS_TOKEN`, явно выбранный `META_GRAPH_API_VERSION`; для тестирования можно добавить `META_TEST_EVENT_CODE`. До этого Pixel/CAPI не отправляют боевые события.
4. После заполнения данных проверить несколько товаров и включить корзину в «Настройки → Включить корзину».
