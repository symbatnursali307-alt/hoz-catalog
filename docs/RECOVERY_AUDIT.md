## Что уже существует, но требует переделки

- корзина считает `qty` как количество упаковок, но хранится только в памяти и отключена через `CART_ENABLED = false`;
- текущая заявка сохраняется как `Client`, а не как `cart_submissions`;
- форма требует имя, город и телефон, хотя новое ТЗ требует обязательным только телефон;
- WhatsApp использует один `WHATSAPP_PHONE`, manager-routing отсутствует;
- интерфейс и сообщение показывают цены без НДС и с НДС одновременно, что противоречит новому ТЗ;
- `lib/pricing.ts` вычисляет НДС через жёстко заданный коэффициент; новая логика должна использовать сохранённую цену `priceWithVat`;
- импорт CSV есть, экспорт отсутствует;
- аналитика, Pixel, CAPI и Meta feed отсутствуют;
- загрузка новых изображений напрямую привязана к Vercel Blob.

## Риски, которые нужно закрыть перед VPS-production

1. `app/api/debug/route.ts` доступен публично и сообщает сведения о конфигурации базы.
2. Ошибки публичных API товаров и категорий возвращают диагностические сведения о `DATABASE_URL`.
3. При отсутствии `ADMIN_SECRET` используется строка `fallback-secret-key`.
4. Старые значения `ADMIN_LOGIN` и `ADMIN_PASSWORD` невозможно извлечь из Vercel; для VPS нужны новые.
5. Нет миграционной истории Prisma.
6. Сборка скачивает Inter с Google Fonts; для независимого VPS лучше хранить шрифт локально.
7. В базе недостаточно достоверных сведений об упаковках для включения новой корзины.

- IP или hostname VPS PS.KZ;
